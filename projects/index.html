🛠️ Сервисы, которые я сделал

Всё это работает в проде дивизиона Центральный DNS. Писал сам, под реальную боль коллег: чтобы не лазить по коммутаторам руками, не искать порты по полчаса и не раздавать доступы к железу всем подряд.

← назад к резюме

SwitchControl

Веб-панель для коммутаторов всех филиалов дивизиона.

  • Находит, на каком порту висит устройство, по MAC или IP
  • Пресеты портов: камера, точка доступа, касса — в пару кликов
  • Инвентарь коммутаторов Cisco и SNR по всем магазинам

Портал управляющих

Простой портал для управляющих магазинами.

  • Состояние сети и оборудования своего филиала — без звонка в IT
  • Только чтение: ничего не сломать

TVIP Control

Управление TV-приставками в магазинах.

  • Настройка приставок и плейлистов централизованно
  • Вход по корпоративной учётке

Web Awacs

Сбор данных с камер видеонаблюдения.

  • Видео с камер прямо в браузере
  • Мониторинг доступности камер

Помощники для Zabbix и MobaXterm

Мелочи, которые экономят часы.

  • Добавление всего оборудования филиала в Zabbix по шаблонам
  • Сессии MobaXterm для всех филиалов собираются сами из таблицы
