Управление сетевым оборудованием SwitchControl

Веб-панель для всех сетевых коммутаторов дивизиона: за секунды находит, куда подключено любое устройство, и настраивает подключение без ручного ввода команд.

  • Находит, на каком порту висит устройство, по MAC или IP
  • Пресеты портов: камера, точка доступа, касса — в пару кликов
  • Инвентарь коммутаторов Cisco и SNR по всем магазинам

Портал для директоров магазинов Портал управляющих

Директор магазина сам видит состояние сети и техники своего магазина — без звонков и заявок в IT.

  • Состояние сети и оборудования своего филиала — без звонка в IT
  • Только чтение: ничего не сломать

Управление телевизорами в магазинах TVIP Control

Что показывают телевизоры во всех магазинах, настраивается из одного окна, а не на каждом экране вручную.

  • Настройка приставок и плейлистов централизованно
  • Вход по корпоративной учётке

Мониторинг Wi-Fi Wi-Fi контроллер

Все точки Wi-Fi магазинов на одном экране: видно, какие работают, а какие отключились, и их можно перезапустить удалённо.

  • Видно, какие точки онлайн, а какие отвалились
  • Перезапуск и перенастройка без выезда

Видеонаблюдение в браузере Web Awacs

Камеры всех магазинов открываются прямо в браузере, а система сама замечает, какие камеры перестали работать.

  • Видео с камер прямо в браузере
  • Мониторинг доступности камер

Автоматизация мониторинга Zabbix + MobaXterm

Новый магазин подключается к системе мониторинга одной формой вместо часа ручной работы, а доступы ко всему оборудованию собираются сами.

  • Добавление всего оборудования филиала в Zabbix по шаблонам
  • Сессии MobaXterm для всех филиалов собираются сами из таблицы
